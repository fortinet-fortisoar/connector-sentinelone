#### Following enhancements have been made to the SentinelOne Connector in version 3.5.2:

- Updated operation name `Create Blacklist Item` to `Create BlockList Item`.
- Added new parameter `SHA-256 Hash Value`, `Group IDs`, and `Site IDs` in `Create BlockList Item` operation.
- Updated parameter name `Hash Value` to `SHA-1 Hash Value` in `Create BlockList Item` operation.
