#### Following enhancements have been made to the SentinelOne Connector in version 3.5.0:

- Added the following operations and playbooks:
    - Get Threat Notes
    - Update Threat Note
    - Delete Threat Note
- The action Custom API Endpoint has been renamed to Execute an API Request.
- The following fields have been added in the HTTP method of the action Execute an
  API Request:
    - PUT
    - DELETE
    - PATCH
